# reLCS
An experimental and unofficial port of GTA LCS to PC.

Here's how to get reLCS working:

1: Get the executable.

2: You're gonna need to search the internet for "Lcs_dist.7z", as it features all of the game files. I sadly cannot link it for piracy reason.

3: You'll need the CUTSCENE, MUSIC, NEWS from the PS2 version of LCS. Copy all three of them in "audio". I sadly cannot link them for piracy reason.

4: You'll need "reLCS-dlls.zip". Extract the content of "reLCS-dlls.zip" in the root folder of the game.

5: You'll need "WEAPON.DAT" from the mobile version of LCS. Will be available as a patch to the one included in "Lcs_dist.7z".

6: If you want the intro fmvs, you can get them here : https://mega.nz/file/SUNEUb5K#AR8A9qyUH8WGM8vHR3mYCeObu_rUy1-_EA1Es63g4Mg , place the "movies" folder in the root folder of the game.
